# 🧠 Python Programming Project 4 – General Knowledge Quiz

##  Project Overview

This project is a simple interactive **General Knowledge Quiz** developed using Python.

The program asks the user three general knowledge questions, checks the answers using `if-else` conditional statements, keeps track of the user's score, provides feedback after each question, and displays the final score at the end.

This project demonstrates fundamental Python programming concepts such as:

- User input
- Variables
- Conditional statements
- Comparison operators
- Boolean logic
- String methods
- Score management
- f-string formatting

---

##  Project Objectives

The main objectives of this project are to:

1. Create an interactive quiz using Python.
2. Accept answers from the user using `input()`.
3. Use `if-else` statements to evaluate answers.
4. Maintain a running score.
5. Handle extra spaces using `.strip()`.
6. Handle different capitalisations using `.lower()`.
7. Provide immediate feedback for each answer.
8. Display the final score using an f-string.
